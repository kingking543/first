# 大乐透号码助手

React + TypeScript + Vite 应用，支持随机选号、规则筛选、生成记录及真实历史开奖统计。生成记录仅保存在当前浏览器中。

## 本地运行与检查

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
npm run check:bundle
```

当前功能无需 API 密钥或环境变量。

## 官方开奖数据

- 来源：[中国体彩网开奖公告](https://www.lottery.gov.cn/kj/kjlb.html?dlt)；采集其公开的大乐透历史接口（gameNo=85）；中央接口不可用时使用[福建体彩网官方历史查询](https://www.fjtc.com.cn/node_309522.htm?gameType=f)页面所用的公开接口。页面按本次成功采集的实际来源显示出处。
- 保留最近 **50 期**真实开奖作为基础数据，列表显示最新 **5 期**；生成器的冷热依据使用完整50期，分析页的出现次数与当前遗漏使用所选的10/30/50期。
- `src/data/official-draws.json` 是已采集的真实快照，包含官方来源、成功核验时间、期号、日期、前区和后区号码。
- `npm run data:update` 从官方接口更新快照。彩种、期号、日期、号码范围、重复号码、连续期号和数据完整性均校验，失败、较旧响应以及重叠期号码/日期不一致均不会覆盖快照。超时、网络错误、408、429 和临时 5xx 最多尝试 3 次，按 1 秒/3 秒退避，Retry-After 最多等待 10 秒；567、401、403 不重试，改为尝试另一官方源。每次超时覆盖请求和响应正文，整体采集最多 120 秒。
- 官方接口的浏览器跨域响应不稳定，因此网页从本站 `data/official-draws.json` 加载数据。Vite 在开发时提供该文件、构建时将同一快照输出到该路径，无需额外后端。
- 页面启动时核对站点数据，允许手动刷新，并在当前浏览器缓存验证过的开奖；加载失败则继续显示已保存的真实数据，明确提示并展示采集时间，不生成模拟开奖。成功读取站点文件不会重置官方核验时间；超过 36 小时未核验时页面显示提醒，每分钟重新判断。以核验时间而非开奖日期判断，避免休市期间误报；设备时间明显早于核验时间会单独提示。
- 完全离线时，前提是页面静态资源已加载；本项目尚未提供离线安装或 Service Worker。

## GitHub Pages 部署与更新

GitHub Actions 在推送到 main、手动触发和每日北京时间 **22:15、23:15** 时从官方采集数据（第二次用于恢复短时失败），检查并构建后发布 Pages。代码推送或手动发布时，官方采集失败会输出告警，使用本地与已发布站点中较新的已验证真实快照，保留原始采集时间。定时采集则保持严格失败，让更新问题可见；已部署页面继续可用，可在 Actions 查看失败原因并重试。

发布前还会核对当前已发布站点的快照及它与本地记录的重叠期一致性，防止官方暂时返回旧数据时把线上期号降级；线上基线核验失败会停止部署（首次接入数据路径返回 404 时除外）。

定时采集产生的快照进入部署产物，不会自动提交回 Git。查看线上实际采集时间应以页面显示为准；本地快照可用 `npm run data:update` 更新。Actions 定时任务可能延迟，公共仓库长期无活动也可能被 GitHub 暂停，不能保证开奖后即时更新。

页面所用规则评分仅用于组合筛选，不是中奖概率或预测准确率。

## 代码结构与性能检查

- `src/App.tsx` 组合页面、官方数据和状态钩子；`src/components/` 按生成结果、历史记录、开奖列表及来源信息等职责拆分。
- `src/lib/lotto.ts` 存放可独立测试的选号、评分、历史校验和复制格式。热号排名随统计变化计算一次，候选评分使用 Set 查找。
- `useLottoGenerator` 惰性读取原有 `lotto_history`，保留有效记录并限制 50 条，避免 StrictMode 首次保存覆盖历史；生成与复制定时器在卸载时清理。
- 统计页通过 React.lazy / Suspense 按需加载，图表不进入首页下载；首次加载有占位，模块失败有提示，选号页仍可使用。
- `npm run build` 生成构建清单，`npm run check:bundle` 检查首页 JavaScript < 400 KB、gzip < 140 KB、各分块 < 500 KB，CI 同样执行预算检查。
- TypeScript 启用 strict 和未使用项检查，显式声明 React 类型；移除未使用的 AI SDK、Express、dotenv 和 autoprefixer。

分析模块加载失败时，“重新加载”会刷新页面后重试；生成记录仍保存在浏览器中。

Runner 的采集步骤使用 `--no-network-family-autoselection --dns-result-order=ipv4first`，避免福建官方主机 IPv4/IPv6 竞争时的过短连接超时。来源抓取和重试只在构建脚本执行，不增加浏览器跨域请求或首页依赖。

## 数据分析

分析页可切换最近10/30/50期，显示实际样本数量、起止期号和日期。切换只影响分析页，号码生成器继续基于完整50期数据。前区高频和当前遗漏前五合并为网格内摘要，同值按号码排序；前后区每个号码均显示出现次数和当前遗漏。当期出现记0期，所选范围内未出现则显示≥N期，不能解释为精确历史遗漏。各区颜色按当前范围的最高次数归一化，仅在同一区内比较。

移除重复频次柱状图与Recharts依赖，分析页仍按需加载；统计期数在切换页面时保留，刷新页面恢复50期。
