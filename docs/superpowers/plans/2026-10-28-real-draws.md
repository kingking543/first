# 官方历史开奖接入

## 范围与架构

沿用现有最近 50 期分析、近 5 期开奖展示，从中国体彩网官方接口采集，同一数据集用于列表、图表和冷热评分。官方接口在真实 Chrome 中跨域失败，因此由 Node 脚本采集，Vite 将真实快照输出为同源 JSON，GitHub Actions 每日采集后构建并部署。无需新增后端或密钥。页面加载站点数据并保留真实快照及缓存，显示来源、采集时间、最新期号和加载状态。

## 验收重点

错误彩种、无效号码、重复期号、错误日期、空列表和不足 50 期的更新必须拒绝。旧响应或错误长度缓存不能覆盖当前完整数据。存储不可用时仍可查看和生成。无模拟开奖；原有生成历史仅补必要的存储异常保护，不改其他行为。不推送或发布；工作流的线上效果需推送后确认。

验证：16 项测试通过，类型检查和生产构建通过。真实官方接口采集成功。Chrome 已验证同源加载、刷新稳定、离线降级、错误数据、存储受限和 /first/ 子路径。已复现并修复本地及跨部署数据降级问题。

发布验证中，GitHub Runner 的官方接口请求返回非成功响应。已补 --allow-saved 发布模式及 3 项回归测试，允许代码发布使用已验证快照，定时采集仍严格失败，不放宽线上基线校验。
