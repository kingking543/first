# 开奖自动更新可靠性

用户已选择优先解决自动更新可靠性、失败重试及数据过期提示。

保留 GitHub Pages 架构、最近 50 期和现有 UI 顺序。中央官方接口为首选；受 Runner 出口拦截时，使用福建省体育彩票管理中心历史查询页实际使用的公开接口。该接口在本机提供的最近 50 期与中央快照逐期完全一致，须在 GitHub Runner 上继续实测。广东官方接口本机数据一致，但 Runner 连接超时，暂不接入；自建国内代理需要新增运行资源，不在本次范围。

仅对网络异常、超时、408、429 和临时 5xx 重试，最多 3 次；567、401、403 不重复请求。每次请求有超时，退避可取消。保留严格定时任务失败行为；推送部署允许保留已验证快照及原始核验时间。发布前仍检查线上基线，避免回退，并校验重叠期号码和日期一致。

快照增加可选官方来源标识，旧快照兼容中国体彩网。网页根据实际采集来源显示出处；成功读取站点文件不等于刚从官方核验。超过 36 小时未成功核验时显示警告，时间以 fetchedAt 为准，避免休市误报；浏览器时钟明显早于核验时间时单独提示。定时任务每日 22:15 和 23:15 运行，第二次用于恢复短时失败。刷新入口仍唯一且位于近五期标题旁，来源板块仍在底部。

验收：真实 Runner 严格采集成功；故障/降级/冲突/旧数据不会改写可信快照；重试和新旧来源兼容测试通过；网页正常、过期、同步失败和时钟异常状态实测，首页 JS 继续满足现有预算。不自动推送 main 或部署生产，等待用户后续发布指令。
